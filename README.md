# 📞 Mechanix Dialer

Dialer App lets you make and manage phone calls, built with Flutter Elinux for Mechanix OS. It provides a simple and intuitive interface for calling contacts, viewing recent calls, and managing your contact list.

## 📦 Install Guide

### 📝 Pre-requisites:

* [Flutter-Elinux SDK](https://github.com/flutter-elinux/flutter-elinux)
* [Dart SDK](https://dart.dev/get-dart)

### 🚀 Steps to run Dialer App:

1. Clone the repository:

```bash
$ git clone https://github.com/mecha-org/mechanix-mechanix_dialer
$ cd mechanix_dialer
```

2. Install Flutter dependencies:

For flutter-elinux:

```bash
$ flutter-elinux pub get
```

3. Build and Run:

For flutter-elinux:

```bash
$ flutter-elinux build
$ flutter-elinux run
```

## 🔑 Key Features

* **Dial Pad**: Place outgoing calls using an easy-to-use numeric keypad.
* **Contacts Management**: Create, edit, search, and delete contacts.
* **Recent Calls**: View incoming, outgoing, and missed call history.
* **Contact Details**: Store and manage multiple phone numbers and email addresses for contacts.
* **Search Contacts**: Quickly find contacts by name or phone number.

### Features Overview

#### Contacts

* Add, edit, delete contacts
* Multiple phone numbers per contact
* Optional email support
* Search functionality

#### Dialer

* Numeric keypad
* Outgoing call flow
* Call controls (mute, speaker, end call)

#### Recents

* Call history
* Incoming, outgoing, and missed calls
* Call timestamps and durations
